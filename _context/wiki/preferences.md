# Working Preferences

## Standards and tools

- Prefer TypeScript.
- Use React and Jest if they fit the Obsidian plugin and project setup.
- Aim for 100% function coverage of in-scope, unit-testable logic; report statement/line and branch coverage separately.
- Target the latest macOS, Windows, and Ubuntu releases available at validation time for the Obsidian desktop plugin. Record the Obsidian version used; the minimum supported Obsidian version is still to be decided.
- No additional formatting, linting, or naming conventions have been specified yet.

## Communication

- Keep progress updates concise.
- Explain relevant tradeoffs when making decisions.

## Working with AI

- Ask the project owner to review all changes. Group related changes together for review when practical.
- The project owner is open to spending another 20-30 minutes planning with AI before implementation decisions are settled.
