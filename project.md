# Project Brief

Stow is a personal Obsidian plugin proof of concept for a desktop board of media-rich cards, inspired by selected Google Keep workflows.

The [POC feature specification](delivery/specs/poc/feature-spec.md) is the source of truth for observable behavior and acceptance criteria. The [project overview](_context/wiki/project.md) records goals, priorities, and open decisions. See the [wiki index](_context/wiki/index.md) for working preferences and other project context, or the [README](README.md) for a concise feature summary.
